# Gizli bilgiler — report-desk

Bu repodaki bütün şifre, anahtar ve bağlantı bilgilerinin envanteri. Repo **private**; bilgisayar değişirse `git clone` sonrası her şey buradan çalışır.

**Kural:** Yeni eklenen her bağlantı bilgisi (FTP, SSH, sunucu, panel, API anahtarı) bu `gizli/` klasörüne konur. Sadece çatının belli bir yerde beklediği dosyalar (kökteki `.env`, `android/key.properties`, `google-services.json` gibi) kendi yerinde kalır ve aşağıda listelenir.
